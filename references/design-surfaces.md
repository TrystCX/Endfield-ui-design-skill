# 设计载体

来源：`docs/design/surfaces/website.md`、`cloud.md`、`game-ui.md`、`promotional.md`。选择一个主导载体后，屏幕内的结构、密度、色彩和装饰都围绕它展开。

## 官网

气质是一份摊开的工业画册：白纸、黑字、大图、一处黄。主舞台是长滚动版面，左缘是只放图标的通高导航轨，首屏底部可有深色停靠坞。

- 以白色和浅灰为主，深色版块只在世界观、影像等内容需要时出现。
- 当前导航项用浅灰底、墨色图标和左缘竖条；悬停展开文字，但不推挤主舞台。
- 最主要的行动在首页通常是黑底白字，黄色用于悬停和当前位置。
- 版块依靠底色、空间和单条色带分隔，不依靠等大的卡片网格。
- 立绘、主视觉或大字可以偏心、越界；辅助信息靠边停靠。
- 形状以直角为主；2–6px 微圆角用于少数控件，圆形用于头像与翻页，胶囊用于分页条、导航器和切换器。

## 云游戏页

这是单独构建的深色首屏 + 白底“更多”画册，不要把它当成官网首页的按钮变体。

- 首屏：整幅主视觉、黑色毛玻璃顶栏、右侧宣传块、一灰一黄两颗胶囊按钮。
- 顶栏约 68px，桌面上使用黑色 80% 叠约 5px 背景模糊；窄屏改为 3rem 顶栏并隐藏文字导航。
- 选中与悬停使用品牌黄 `#FFF100`；“开始游戏”按钮使用按钮黄 `#F2E200`，不要将两种黄色合并。
- 导航项有“图标 + 竖线 + 文字”，4px 圆角；浮层约 8px 圆角；按钮组件统一胶囊。
- “更多”视图回到白底，使用斜纹、刻度、角标、注册色条等编辑母题。
- 账号 SDK 弹窗是鹰角通用组件的终末地皮肤，不作为终末地设计规则的证据。

## 游戏界面

游戏 UI 是高密度、分区停靠的独立体系。它可以使用亮色或暗色表面，并使用分工明确的角色色。

- 先从界面家族选结构：运行/系统枢纽、地图/区域、角色/装备、仓库/商城/矩阵、技能树/流程、数据简报/监控、通讯/信息工具。
- 颜色承担通知、增益、数据、地区、危险、确认和特殊等不同语义；不要把角色色当装饰彩虹。
- 切角、斜楔、角括号、弧线、刻度和胶囊按含义组合；不要所有控件都切角。
- 侧轨、顶栏、信息面板和工具带承载密度；主内容应有明确焦点，不要让每个数据块拥有同等权重。
- 游戏风格可以使用社区证据，但要在输出中标注“社区”或“推断”。

## 宣传物料

宣传物料不是游戏界面的截图化版本。它以版本、角色、地区或活动主题接管画面，结构可更自由，允许编辑痕迹。

- 先定体裁和主题，再决定主视觉、刊头、章节和信息层级。
- 主题色可整页接管，但危险、成功等功能语义仍要保持可辨认。
- 可加入批注、红笔圈、荧光标记、印章、胶带、贴纸等“人的痕迹”，但这些装饰应服务于体裁。
- 版本日历、导览、公文部件可以跨体裁复用；不要把官网导航或游戏 HUD 原样搬成海报。
- 真实数字、日期、名称和素材来源必须可核验，或明确标为占位。

## 载体隔离检查

交付前逐屏回答：

1. 这一屏的主导载体能否用一句话说明？
2. 主要行动、文字层级和密度是否符合该载体？
3. 是否把另一个载体的按钮、纹理、字体或密度无理由混入？
4. 去掉黄色和纹理后，信息架构是否仍然成立？
