# 分节标题

来源：`docs/design/elements/section-title.md`、`SectionTitle`。

## 三种形态

| 形态 | 结构 | 适用 |
| --- | --- | --- |
| 标准 | 灰色滑块 + 斜箭头 + 英文副层 + 中文标题 | 普通版块的一级标题 |
| 色带 | 通栏或局部信号色带 + 工业线稿 + 英文副题 | 亮暗版块过渡、大章节开始 |
| 竖排侧签 | 通高色带 + 旋转文字 + 可选线稿 | 横向轮播、列表和宽内容 |

标准标题中真正的语义标题是中文 `h2`；英文副层可在重复翻译时对辅助技术隐藏。标准入场可以按滑块滑入、箭头转正、文字淡入三步进行，每步约 300ms，只播放一次。

色带一页通常最多一到两条，只放墨色文字和线稿，不塞按钮或照片。竖排侧签使用 `writing-mode` 参与布局；窄屏改回横向标准标题。
