# 镂空字与微文字

来源：`docs/design/elements/ghost-and-micro-text.md`、`GhostText`、`theme.css`。

- 镂空巨字是章节索引和背景层，不是主标题；可用 `font-size: clamp(5rem, 10.4vw, 12.5rem)`、低对比描边或斜纹填充。
- 巨字可以越过边界并被局部裁切，但必须 `pointer-events: none`，不能影响阅读或点击。
- 微文字用于真实的分节、版本、日期、坐标、编号、进度和状态；它不负责填空白。
- 微文字应有明确方向和层级，避免虚假的遥测、乱码、随机序列号和不可验证的法律文案。
- 镂空字和微文字都应对辅助技术隐藏或提供不重复的语义替代。
