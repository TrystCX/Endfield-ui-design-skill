# 网格、等高线、点阵

来源：`docs/design/elements/grid-contour-dots.md`、`Texture`、`utilities.css`。

| 类型 | 参考值 | 使用方式 |
| --- | --- | --- |
| 点阵 | 点径约 1–2px，间距 12–24px，8–14% 墨色 | 铺在面上，不用于窄条 |
| 工程网格 | 64–96px 间距、1px 线、≤10% 墨色 | 大背景，不作为布局网格 |
| 等高线 | 5–8 圈、1px、15–20% 墨色 | 偏向一角并被边缘截断 |

纹理默认由墨色与透明混合，随亮暗主题继承；它必须弱于真实边线、地图路径和表格线。等高线使用原创 SVG 或遮罩，放在空的装饰层，不能遮挡内容或随意盖在文字上。
