# 页面组合案例

来源：`apps/docs/stories/ContentPage.stories.tsx`、`DispatchPage.stories.tsx`、`SettingsPage.stories.tsx`、`ListPage.stories.tsx`、`DepotPage.stories.tsx`。

## 官网气质内容页

适合低到中密度内容：页头、分节标题、页签、面板、媒体轮播、头像切换、排期和图片查看。主内容应有偏心视觉锚，右侧可放页内目录；头像在窄于约 448px 时转为横排，排期在自身容器内横向滚动。

## 调度台

适合高密度工具：宽屏是侧轨，窄于约 1024px 切换顶栏和全屏菜单；主体用工具栏 + 表格，包含筛选、日期范围、排序、勾选、行展开、行内操作、右键菜单和悬浮卡。首列在窄屏冻结，表格自身横向滚动。

## 设置页

适合表单和反馈：页头、步骤条、字段、校验、选择、组合框、标签输入、文件上传、验证码、分段选择、滑块和折叠面板。示例流程是提交 → 错误 → 修正 → 保存，持续错误用提示条，成功用 Toast。

## 列表页

适合检索、筛选和资源浏览：页头、搜索、排序、筛选、网格/列表切换、分页和侧栏。窄屏把筛选收进抽屉，时间线限制高度并在自己的滚动区滚动。

## 仓库页

适合游戏 UI 语气的高密度资源：楔形页签、物品格、取景角、刻度圆环、菱形选择、完成横幅、危险操作区和确认弹窗。它可以借用游戏家族的结构，但不要自动引入 `src/game` 的官方素材。

## 组合原则

每个页面先确定一个主导家族和一项 signature。组件可以跨家族复用，外观、密度和主题必须服从当前家族；不要把五个示例页的所有母题同时堆在一页里。
