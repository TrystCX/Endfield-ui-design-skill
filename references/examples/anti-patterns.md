# 反模式

## 视觉反模式

- 黑底黄字覆盖整页，或者把暗色当成唯一正确主题。
- 所有组件切角、所有容器胶囊化、所有卡片都描黄边。
- 把官网按钮、云游戏按钮、游戏 HUD 和宣传海报混成一套组件。
- 用霓虹辉光、玻璃拟态、六边形、扫描线或持续漂浮代替真实层级。
- 每个版块都是居中标题 + 三张等宽卡片。
- 用伪技术英文、假坐标、随机编号和虚假遥测填空白。

## 语义反模式

- 在白底上使用 `#FFFA00` 做正文或细线。
- 用橙色表示危险、用红色做普通装饰、用彩虹色替代角色语义。
- 把主题色接管应用到危险、成功和警告，破坏状态语义。
- 用颜色作为唯一的错误、选中、完成或禁用提示。

## 工程反模式

- 把视觉 token 硬编码进组件，而不是通过语义变量适配主题。
- 用 `clip-path` 裁掉键盘焦点环或缩小触屏命中区。
- 用全局 `overflow-x: hidden` 掩盖装饰层或网格错误。
- 手写只支持鼠标的浮层，忽略键盘、Escape、焦点管理和屏幕阅读器。
- 复制源仓库 Game 入口中的官方图片、Logo、截图或商业字体。
