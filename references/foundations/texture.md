# 纹理与装饰

来源：`docs/design/foundations/texture.md`、`docs/design/elements/grid-contour-dots.md`、`packages/ui/src/styles/utilities.css`。

## 纹理预算

纹理是结构的低对比背景层，不是内容。单屏通常选一到三套相关纹理；去掉纹理后，阅读顺序、行动和状态必须仍然成立。纹理放在独立层，`pointer-events: none`，局部裁切，并在高对比和打印场景下隐藏。

## 主要类型

| 类型 | 典型规格 | 适合 |
| --- | --- | --- |
| 点阵 | 1–2px 点，12–24px 间距，约 8–14% 墨色 | 面、弹窗、空状态背景 |
| 工程网格 | 64–96px 间距，1px 线，≤10% 墨色 | 大面积蓝图底；不能替代真实坐标系 |
| 等高线 | 5–8 圈不等间距闭合曲线，15–20% 墨色 | 角落和容器边缘，允许被截断 |
| 斜纹 | 约 6px 条带间距 | 窄条、按钮底、标签和分节带 |
| 注册色条 | 青、品红、黄的窄色条 | 印刷语气、刊头、宣传物料 |
| 警示条纹 | 黑黄或主题色斜条 | 危险操作区、边界提示；不作普通装饰 |

点阵和网格可用 CSS 渐变，等高线应使用原创 SVG 或遮罩。装饰网格必须弱于真实边线、路径、表格线和连接线。

## 使用规则

- 文字区下方先垫实色，或让纹理在文字区淡出。
- 真实地图、图表或工程坐标已经存在时，不要再铺一层同语义的装饰网格。
- 纹理不应撑开布局、挡住焦点环或制造横向滚动。
- 不把纹理当作所有组件的统一背景。
