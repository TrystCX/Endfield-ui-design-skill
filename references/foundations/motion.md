# 动效

来源：`docs/design/foundations/motion.md`、`packages/ui/src/styles/theme.css`、`packages/ui/src/lib/motion.ts`。

## 规则

- 短：普通反馈集中在 200–300ms；按下可用约 50ms；大型入场可到 400–600ms。
- 硬：使用位移、擦入、形变和明暗反转；避免弹跳、回弹、放大、漂浮和过度阴影。
- 有因果：动效解释状态从哪里来、向哪里去。浮层从触发侧进入，选中指示滑向新项，内容移除后其余项补位。
- 戏剧性留给入场：闪烁点亮、跑马灯和加载层只在确有内容理由时使用。
- 可关闭：`prefers-reduced-motion: reduce` 时停在终态，清除延迟和滚动动画。

## 时间与缓动

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `duration-instant` | 50ms | 按下反馈 |
| `duration-fast` | 200ms | 颜色、透明度 |
| `duration-base` | 300ms | 位移、展开、形变 |
| `duration-slow` | 400ms | 较大面积移动 |
| `duration-slower` | 600ms | 一次性入场 |
| `ease-standard` | `ease` | 默认 |
| `ease-emphasis` | `ease-in-out` | 往返或展开 |
| `ease-exit` | `ease-out` | 进入、离开 |
| `linear` | `linear` | 旋转、跑马灯、闪烁 |

## 常用模式

- 悬停主要换色，不上浮、不放大、不加重阴影。
- 选中状态可用底块滑动、文字让位给箭头、左缘条或角括号进入。
- 关闭可以旋转 90° 或向触发侧退出，但不需要和入场完全对称。
- 大标题入场可采用滑块 → 箭头转正 → 文字淡入的三步序列，每步约 300ms，且只播放一次。
- 浮层只做 4–8px 的方向位移加淡入，不使用长距离飞入。

## 反模式

- 用循环动画让静态页面持续漂浮。
- 用弹簧曲线制造游戏化弹跳。
- 同一屏同时播放多套高对比动画。
- 在减少动态效果时只缩短时长却保留错开的入场。
