# 形状

来源：`docs/design/foundations/shape.md`、`docs/design/overview.md`、`packages/ui/src/styles/theme.css`。

## 形状语义

| 形状 | 主要语义 | 适合 |
| --- | --- | --- |
| 直角矩形 | 文档、内容、基础面板 | 官网内容区、表格、面板 |
| 切角 / 斜楔 | 机械、导航、权限、行动 | 游戏 UI 的行动块、楔形页签、物品格状态 |
| 圆与弧 | 仪器、目标、头像、技能 | 头像、进度环、取景器、地图半径 |
| 胶囊 | 短状态、筛选、资源、切换 | 分页条、导航器、资源标签、云游戏按钮 |

形状之间的对比本身就是层级语言。不要将所有控件切角，也不要把所有内容做成胶囊。

## 圆角与边线

源令牌为 `radius-xs: 2px`、`radius-sm: 4px`、`radius-md: 6px`；胶囊与圆形使用完整圆角。官网默认直角，只有按钮、页签、小标签等少数控件使用不明显的微圆角；云游戏页的按钮和浮层分别使用胶囊与约 8px 圆角。

默认层次依靠表面差、单条边线、左缘色条或填充反转，不给每个块围一整圈边框。整圈边框适合浮层、明确的信息容器、物品格和需要闭合边界的控件。

## 切角实现

切角可以用 `clip-path` 或伪元素实现，但焦点环必须位于不会被裁剪的外层。切角是组件变体的一部分，不应暴露成让使用者随意组合的 `rounded` / `cut` 开关。

## 阴影

阴影主要是零偏移的环境阴影：`0 0 4px`、`0 0 8px`、`0 0 12px`、`0 0 24px`，透明黑约 25–30%。云游戏页的浮层可以向下偏移并配合背景模糊；不要把阴影、玻璃和霓虹当成通用风格。

## 选中与强调

优先使用一种明确的状态语言：填充反转、左缘条、角括号、选中环或形状滑动。状态不能只靠颜色表达；键盘焦点使用 `focus-visible` 的 2px 焦点环与 2px 间隔。

## 反模式

- 全站所有元素统一切角。
- 每张卡片都有黄色描边、阴影或发光。
- 用 `border-radius` 代替语义形状选择。
- 让 `clip-path` 裁掉焦点环或触屏点击区域。
