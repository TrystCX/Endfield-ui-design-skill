# 图标

来源：`docs/design/foundations/iconography.md`、`packages/ui/src/icons/`、组件测试与故事。

## 角色

图标是导航、状态和操作的快速索引。官网导航轨可以只显示图标，悬停再显示文字；云游戏页导航通常是图标 + 竖线 + 文字；游戏 UI 的图标可以嵌入圆、弧、角括号和稀有度层。

## 画法

- 建立统一网格、视口和线宽；同一组图标保持视觉重量。
- 用继承的语义文字色控制图标，避免在 SVG 内写死主题颜色。
- 纯图标按钮必须有可访问名称；装饰图标使用 `aria-hidden`。
- 图标状态应与文字、形状或位置配合，不能只用颜色区分。
- 自制图标优先使用几何、刻度、箭头、方括号和简洁轮廓，不复制官方图标资产。

## 状态

默认、悬停、按下、当前、禁用和错误状态优先通过语义色、底色、角括号、边条或反转表达。焦点环不能被 SVG、`clip-path` 或装饰层遮住。
