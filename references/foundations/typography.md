# 字体与文字

来源：`docs/design/foundations/typography.md`、`packages/ui/src/styles/theme.css`。

## 四种文字角色

1. **阅读字体**：CJK 无衬线，负责正文、字段、说明和可读中文。
2. **展示字体**：宽体或几何体，负责页面标题、版本名和大字；只在内容需要时使用。
3. **拉丁结构字体**：用于分节名、编号、导航、英文标签和结构副层。
4. **技术/等宽字体**：用于坐标、代码、版本、时间、表格数字或需要稳定列宽的读数。

源仓库的自由字体回退链为：`HarmonyOS Sans SC` / `Noto Sans SC` / `Source Han Sans SC` / `PingFang SC` / `Microsoft YaHei`；展示可用 `Archivo`，拉丁副层可用 `Outfit`，技术层可用 `Space Grotesk`，等宽层可用 `JetBrains Mono` 或系统等宽字体。不要复制源项目明确排除的商业字体。

## 字阶令牌

| 令牌 | 尺寸 | 典型用途 |
| --- | --- | --- |
| `micro` | 10px | 技术微标签 |
| `xs` | 12px | 英文小标、页码 |
| `sm` | 14px | 标签、导航 |
| `base` | 16px | 正文 |
| `lg` | 20px | 按钮、页签 |
| `xl` | 24px | 英文分节标题 |
| `2xl` | 32px | 中文分节标题 |
| `3xl` | 40px | 色带标题 |
| `4xl` | 52px | 页面标题、名称 |
| `5xl` | 72px | 代号、大型英文 |
| `6xl` | 96px | 主视觉大字 |
| `ghost` | `clamp(5rem, 10.4vw, 12.5rem)` | 镂空巨字 |

字重、字距和行高应服从内容层级。技术英文可以使用 `tabular-nums`；不要为了“像技术界面”而生成无意义的编号、假遥测或乱码。

## 中英关系

中文承担阅读，英文承担结构。可读的英文微文字可以是分节名、编号、坐标、版本和真实状态；它不应遮挡中文标题或成为伪装饰。镂空字和低对比巨字只能索引章节或阶段，不能取代真实标题。

## 响应式与可读性

- 长文案优先保持可读宽度，允许标题换行，不让按钮或数字被折成竖条。
- 触屏控件的文字与点击区域分开考虑；点击区至少 40 × 40px。
- 在窄屏上缩小装饰巨字或隐藏它，而不是压缩正文到不可读。
- 字体加载失败时，层级关系仍应由系统回退字体和字号成立。

## 反模式

- 所有内容使用同一种展示字体。
- 用英文小字填充空白，却不提供真实信息。
- 用黄色正文代替强调语义。
- 将镂空字、编号或坐标当成主标题和真实数据。
